# Gallery Folder

## Cara Menggunakan Gallery

Folder ini digunakan untuk menyimpan gambar-gambar yang akan ditampilkan di halaman Gallery website Anda.

### Cara Menambahkan Gambar:

1. **Simpan gambar** Anda ke folder ini (`/public/galleryku/`)
2. **Format yang didukung**:

   - `.jpg` / `.jpeg`
   - `.png`
   - `.gif`
   - `.webp`

3. **Gambar akan otomatis muncul** di halaman Gallery tanpa perlu coding

### Tips:

- Gunakan nama file yang deskriptif (nama file akan ditampilkan sebagai judul)
- Contoh: `project-design-1.jpg`, `artwork-illustration.png`
- Untuk hasil terbaik, gunakan gambar dengan resolusi yang baik
- Gambar akan otomatis di-resize dan di-optimize oleh browser

### Contoh Struktur:

```
galleryku/
├── project-1.jpg
├── artwork-nature.png
├── design-mockup.jpg
└── illustration-character.png
```

Setiap kali Anda menambahkan, menghapus, atau mengganti gambar, website akan otomatis mendeteksi perubahan saat di-reload.

## How to Use Gallery (English)

This folder is used to store images that will be displayed on your website's Gallery page.

### How to Add Images:

1. **Save your images** to this folder (`/public/galleryku/`)
2. **Supported formats**:

   - `.jpg` / `.jpeg`
   - `.png`
   - `.gif`
   - `.webp`

3. **Images will automatically appear** on the Gallery page without any coding needed

### Tips:

- Use descriptive filenames (filename will be displayed as title)
- Example: `project-design-1.jpg`, `artwork-illustration.png`
- For best results, use high-resolution images
- Images will be automatically resized and optimized by the browser

Whenever you add, remove, or replace images, the website will automatically detect changes on reload.
